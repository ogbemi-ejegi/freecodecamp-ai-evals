## Architecture & What We Evaluate

This project evaluates a stateful **CloudOps Support Agent** (`src/agent.py`) equipped with an Enterprise SLA Runbook retriever (`src/retrieval.py`) and two operational tools (`src/tools.py`):
1. `check_service_status(region)` — Read-only status & downtime verification tool.
2. `issue_sla_credit(account_id, amount_usd)` — High-risk financial refund tool governed by strict SLA thresholds (>45 minutes downtime required).

### The 5-Stage Evaluation Pipeline:
* **Module 1: Structured Agent Tracing (`src/agent.py`)** — Capturing `user_input`, `actual_output`, `retrieval_context`, and `tools_called` for every execution.
* **Module 2: Custom Cloud Judge via OpenRouter (`evals/openrouter_judge.py`)** — Subclassing `DeepEvalBaseLLM` to run `deepseek/deepseek-v4-pro-0813` as an independent LLM-as-a-Judge with zero local GPU/RAM overhead.
* **Module 3: RAG Grounding & Tool Trajectory Evals (`evals/test_02_rag_and_trajectory.py`)** — Enforcing zero hallucination (`FaithfulnessMetric`), strict tool execution order (`ToolCorrectnessMetric`), and domain policy rubrics (`GEval`).
* **Module 4: Adversarial Red-Teaming & Security Gates (`evals/test_03_red_team_security.py`)** — Defending against authority spoofing (`SYSTEM OVERRIDE`), unauthorized refund execution, and cross-tenant PII/credential exfiltration.
* **Module 5: CI/CD Pull Request Gating (`.github/workflows/ai_eval_gate.yml`)** — Automated GitHub Actions workflow that blocks Pull Requests whenever prompt or code changes degrade evaluation metrics.

## Quickstart & Local Setup

### 1. Clone the Repository & Create a Virtual Environment

```bash
git clone [https://github.com/EjegiOgbemi/freecodecamp-ai-evals.git](https://github.com/EjegiOgbemi/freecodecamp-ai-evals.git)
cd freecodecamp-ai-evals
python -m venv .venv
```

**Activate the virtual environment:**

*   **Windows (PowerShell):**
    ```powershell
    .\.venv\Scripts\Activate.ps1
    ```
*   **Linux / macOS / WSL2:**
    ```bash
    source .venv/bin/activate
    ```

### 2. Install Dependencies

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Configure Your OpenRouter API Key

Copy `.env.example` to `.env` and add your OpenRouter API key:

```bash
cp .env.example .env
```

**Code snippet:**
```env
OPENROUTER_API_KEY="sk-or-v1-your-key-here"
AGENT_MODEL="deepseek/deepseek-v4.1-flash"
JUDGE_MODEL="deepseek/deepseek-v4-pro-0813"
```

## Running the Evaluation Suites

### 1. Run Module 2: Deterministic Audit vs. G-Eval Rubric Judge

```bash
python -m evals.test_01_deterministic_and_geval
```

### 2. Run Module 3: RAG Faithfulness & Agent Tool Trajectory Suite

```bash
deepeval test run evals/test_02_rag_and_trajectory.py
```

### 3. Run Module 4: Adversarial Red-Teaming & Security Gate

```bash
deepeval test run evals/test_03_red_team_security.py
```

## Step 4: Push to GitHub & Trigger Your Live CI/CD Pipeline

Run these commands sequentially in your VS Code terminal (`C:\Users\Public\Desktop\freecodecamp-ai-evals`):

```powershell
git init
git add .
git status
```

*(Verify in the git status output that `.env` and `.venv` are NOT listed!)*

**Commit your code:**

```powershell
git commit -m "feat: complete 5-module AI Evals course codebase and CI/CD gate"
git branch -M main
```

Create a new public repository named `freecodecamp-ai-evals` on your GitHub account, add your `OPENROUTER_API_KEY` under **Settings → Secrets and variables → Actions → New repository secret**, and push:

```powershell
git remote add origin [https://github.com/](https://github.com/)<your-github-username>/freecodecamp-ai-evals.git
git push -u origin main
```
